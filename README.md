Google Dorking Smart Search Tool.

This project simplifies Google Dorking by allowing users to generate advanced search queries using a simple interface.

## Features
- Search PDFs, ZIPs, documents, and download links
- No backend required
- Easy to use
- Educational purpose only

## How to Use
1. Enter book/game/software name
2. Select file type
3. Click search

## Ethical Notice
This tool only generates search queries and does not access private data.
